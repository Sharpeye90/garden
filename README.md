# Ритм сада

Рабочая alpha цифрового помощника для садоводов Московской и Тверской областей.

## Что уже работает

- экран «Сегодня» с погодой, приоритетными задачами и объяснениями;
- переход по дням с задачами и погодой на выбранную дату;
- выбор погодной точки по населённому пункту или через геолокацию устройства с немедленным округлением координат;
- вход по одноразовой email-ссылке и защищённая серверная сессия;
- выполнение, частичное выполнение, пропуск и перенос задач;
- 2D-план участка с сеткой в метрах, перетаскиванием, масштабированием, вращением, сезонными слоями и безопасной очисткой с отменой;
- каталог овощных, плодовых и декоративных растений;
- размещение конкретных посадок на плане с привязкой к грядке, теплице или клумбе;
- автоматическая безопасная задача после размещения и переход от задачи к посадке;
- календарь цветения с диапазонами и подтверждением стадии;
- журнал наблюдений и выполненных работ со связью с посадкой;
- локальная офлайн-копия в IndexedDB и синхронизация с PostgreSQL;
- PWA-манифест и service worker;
- погодный адаптер и поиск населённых пунктов Open-Meteo;
- очередь вопросов советнику и схема серверного хранения;
- изолированный публичный деморежим с локальным хранением в браузере.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`.

Без `DATABASE_URL` интерфейс и офлайн-копия доступны, а серверная синхронизация
возвращает понятный статус недоступности. Для полной локальной проверки задайте
строку подключения к PostgreSQL.

Доступ закрыт по умолчанию и управляется инвайтами в PostgreSQL. Для пилота
почтовый сервис не обязателен: создайте инвайт и одноразовую ссылку, затем
передайте её пользователю лично:

```bash
npm run invites -- add gardener@example.ru --note "Осенний пилот"
npm run invites -- link gardener@example.ru
npm run invites -- list
npm run invites -- check gardener@example.ru
npm run invites -- remove gardener@example.ru
npm run invites -- remove gardener@example.ru --logout
```

Ссылка действует 15 минут по умолчанию; срок можно изменить флагом
`--minutes`. Команды читают `DATABASE_URL` и `GARDEN_APP_URL` из окружения или
локального `.env`. `remove`
запрещает новые входы и отзывает ещё не использованные ссылки; `--logout`
дополнительно завершает активные сессии. В рабочем контейнере CLI находится в
`dist/standalone/scripts/invites.mjs`, поэтому изменение списка не требует
пересборки приложения.

Когда появится подтверждённый домен, автоматическую отправку можно включить
через `GARDEN_EMAIL_FROM` и `RESEND_API_KEY` из `.env.example`. Ручные ссылки
продолжат работать независимо от почтового провайдера.

## Данные

Клиент всегда сохраняет безопасную офлайн-копию задач и журнала. Геометрия редактируется только онлайн. Участок можно выбрать поиском по городу, посёлку или деревне либо определить по устройству. Координаты для погоды округляются до 0,05 градуса, точный адрес не сохраняется, а погодная точка не связана с локальной системой координат плана. При ручном поиске название места передаётся GeoNames через Open-Meteo.

## Безопасность рекомендаций

Детерминированные правила остаются источником истины. AI может только ранжировать и объяснять уже разрешённые правила. Alpha не предлагает препараты, дозировки и схемы химической обработки. Демонстрационные советы нельзя считать заменой профессиональной агрономической консультации.
