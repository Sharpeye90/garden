# Ритм сада

Рабочая alpha цифрового помощника для садоводов Московской и Тверской областей.

## Что уже работает

- экран «Сегодня» с погодой, приоритетными задачами и объяснениями;
- выполнение, частичное выполнение, пропуск и перенос задач;
- 2D-план участка с сеткой в метрах, перетаскиванием, масштабированием, вращением и сезонными слоями;
- каталог овощных, плодовых и декоративных растений;
- календарь цветения с диапазонами и подтверждением стадии;
- журнал наблюдений;
- локальная офлайн-копия в IndexedDB и синхронизация с PostgreSQL;
- PWA-манифест и service worker;
- погодный адаптер Open-Meteo;
- очередь вопросов советнику и схема серверного хранения;
- приватный однопользовательский режим для alpha в K2 Cloud.
- изолированный публичный деморежим с локальным хранением в браузере.

## Локальный запуск

Требуется Node.js 22.13 или новее.

```bash
npm install
npm run dev
```

Приложение откроется на `http://localhost:3000`.

Без `DATABASE_URL` интерфейс и офлайн-копия доступны, а серверная синхронизация
возвращает понятный статус недоступности. Для полной локальной проверки задайте
строку подключения к PostgreSQL.

## Проверки

```bash
npm run typecheck
npm run lint
npm test
```

## K2 Cloud

Развёртывание создаёт приватную VM и управляемый PostgreSQL 16 в существующих
VPC и подсети. Публичный IP не назначается, приложение доступно через VPN на
порту `8000`, а база принимает соединения только от VM приложения.

Если к VM отдельно привязан EIP, Caddy публикует деморежим по HTTPS на порту
`443` и перенаправляет HTTP с порта `80`. Для EIP используется автоматически
обновляемый short-lived сертификат Let's Encrypt. Публичный прокси разрешает
только интерфейс и погодный API; состояние сада, очередь советника и health
endpoint снаружи недоступны. Полный режим остаётся на приватном адресе `:8000`.

Параметры K2 читаются из локального `.env`, который исключён из Git. Команды:

```bash
./scripts/k2-terraform.sh plan
./scripts/k2-terraform.sh apply
./scripts/k2-deploy-app.sh
```

Подробности находятся в `infra/k2/README.md`.

## Данные

Клиент всегда сохраняет безопасную офлайн-копию задач и журнала. Геометрия редактируется только онлайн. Координаты для погоды округляются до 0,05 градуса и не связаны с локальной системой координат плана.

## Безопасность рекомендаций

Детерминированные правила остаются источником истины. AI может только ранжировать и объяснять уже разрешённые правила. Alpha не предлагает препараты, дозировки и схемы химической обработки. Демонстрационные советы нельзя считать заменой профессиональной агрономической консультации.
