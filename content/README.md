# Контент alpha

Таблицы в этой папке — исходный формат будущего версионируемого импорта.

- `plants.csv` содержит нормализованные названия и интервалы цветения.
- `care-rules.csv` содержит только непубликуемые примеры структуры правил.

Правило нельзя переводить в `publishable=true`, пока для него не указаны проверяемый источник, версия, диапазон применимости, риск и минимальная уверенность. AI не имеет права создавать новые действия вне опубликованных правил.
